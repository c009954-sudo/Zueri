# Daily Spark ✦

A tiny, responsive random idea generator for finding your next mini-project, creative prompt, or everyday challenge.

## Run it

Open `index.html` in any modern browser. No dependencies, build tools, account, or setup required.

## Features

- Random ideas from a small built-in collection
- Responsive dark interface
- Copy an idea to the clipboard
- Accessible focus states and live updates
- No tracking or external libraries

## Customize

Edit the `ideas` array in `index.html` to add your own prompts.
